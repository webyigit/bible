오늘의 영상 — 재생목록 자동 연동 (선택)

매일 영상이 하나씩 추가되는 유튜브 재생목록을 등록하면, 재생목록의 가장 마지막(최신) 영상을 자동으로 가져와 "오늘의 영상" 카드에 표시합니다. 하루에 한 번만 확인하며, Firebase가 연결되어 있으면 그룹 전체 화면에 공유됩니다.

API 키는 Google Cloud Console에서 무료로 발급받을 수 있습니다 (YouTube Data API v3 사용 설정 → 사용자 인증 정보 → API 키 만들기).
